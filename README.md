Snapforge Lab provides independent security audits and fixes for AI‑built applications such as Replit, Lovable, Bolt and Supabase. It offers a free read‑only audit, paid launch‑fix sprints, ongoing monitoring, and custom business‑app development, helping developers secure data, secrets, CORS and webhooks.

**Areas:** Security · Audits · AI · Replit · Web Development

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Snapforge Lab: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
